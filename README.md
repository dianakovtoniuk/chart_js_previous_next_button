# Chart.js Previous and Next Buttons

A bar chart with 52 weeks of data built with Chart.js 3.6.0 in plain HTML, CSS and JavaScript. The Previous and Next buttons move the visible range of the chart one week block at a time.

## Getting started

Open `index.html` in your browser. No build step or installation is needed, Chart.js is loaded from a CDN.

## Project structure

```
.
├── index.html
├── style.css
└── script.js
```

`script.js` is split into three blocks: data, config and render, followed by the button logic.
